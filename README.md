# 影视仓 / TVBox 配置（含直播源）

一份自包含的单仓配置：**25 个点播采集站 + 3 组直播源（134 个频道）**，全部写在
`config.json` 里，不依赖任何外部文件或解析器（不需要 spider jar）。

## 配置地址

```
https://cdn.jsdelivr.net/gh/foxfox123/tv-keep@config/config.json
```

备用地址（国内有时连不上 raw）：

```
https://raw.githubusercontent.com/foxfox123/tv-keep/config/config.json
```

## 怎么用

1. 打开影视仓 / 宝盒 / TVBox 系 App
2. 设置 → 配置地址（或「导入配置」）→ 粘贴上面的地址 → 确定
3. 首次加载需要几秒，之后首页就能出片

## 内容说明

- **点播**：25 个纯 HTTP 采集接口，2026-11-12 实测存活（猫眼、360资源ZZ、360资源、
  爱蛋、百度、光速、海豚、金鹰、快车、魔都、闪电API、速播、索尼、天涯、无尽、新浪、
  鸭鸭、最大、爱奇艺等）
- **直播**：3 组 134 频道，内嵌在 config 的 `lives` 字段里
  - 河南地方（13 个）
  - IPV4线路（91 个，CCTV 全套 + 各省卫视）
  - 央视·卫视(游魂源)（30 个）
- 直播源不依赖外部 m3u，换设备/重启都不会丢

## 注意

- 采集站的可用性会随时间变化，失效后需要重新探活替换
- 直播源是公开 IPTV 地址，画质和稳定性取决于源站，CCTV-1 等主力频道有多个备用地址

---

本分支只放这份配置，与 `main` 分支的自动保活任务互不影响。
